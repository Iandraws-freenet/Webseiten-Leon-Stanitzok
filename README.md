# HTML & CSS Übungsaufgaben für Einsteiger

Willkommen! Diese Sammlung enthält **10 Aufgaben**, mit denen du Schritt für Schritt HTML und CSS lernst.
Die Aufgaben werden langsam schwieriger – fang also bei Aufgabe 01 an.

## So arbeitest du mit den Aufgaben

1. Öffne den Ordner der Aufgabe (z. B. `01-erste-webseite`).
2. Lies zuerst die Datei **`README.md`** – dort steht, was zu tun ist.
3. Öffne `index.html` und `style.css` in deinem Editor (z. B. VS Code).
4. Suche nach den Kommentaren mit **`TODO`** – dort musst du etwas ergänzen.
5. Öffne `index.html` im Browser (Doppelklick oder Rechtsklick → „Öffnen mit“ → Browser).
6. Nach jeder Änderung: **Speichern** (Strg + S) und im Browser **neu laden** (F5).
7. Hake die Punkte in der To-do-Liste ab, wenn du fertig bist.

> 💡 Tipp: In VS Code gibt es die Erweiterung **„Live Server“**. Damit lädt sich die Seite automatisch neu.
