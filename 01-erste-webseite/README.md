# Aufgabe 01 – Deine erste Webseite ⭐

## Ziel
Du baust eine einfache Webseite über dich selbst.

## Das lernst du
- Das HTML-Grundgerüst (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Überschriften `<h1>` bis `<h6>`
- Absätze `<p>`
- Text hervorheben mit `<strong>` und `<em>`

## To-do
- [ ] Öffne `index.html`. Das Grundgerüst ist schon da.
- [ ] Ändere den Text im `<title>` zu **„Über mich“**. (Den Titel siehst du im Browser-Tab.)
- [ ] Schreibe eine `<h1>`-Überschrift mit deinem Namen.
- [ ] Schreibe einen Absatz `<p>`, in dem du dich kurz vorstellst (2–3 Sätze).
- [ ] Füge eine `<h2>`-Überschrift **„Meine Hobbys“** hinzu.
- [ ] Schreibe einen Absatz über deine Hobbys.
- [ ] Mache **ein Wort fett** mit `<strong>` und **ein Wort kursiv** mit `<em>`.
- [ ] Füge eine `<h2>`-Überschrift **„Mein Ziel in der IT“** und einen Absatz dazu hinzu.
- [ ] Öffne die Datei im Browser und prüfe das Ergebnis.

## Tipps
```html
<h1>Das ist eine große Überschrift</h1>
<p>Das ist ein Absatz mit <strong>fettem</strong> und <em>kursivem</em> Text.</p>
```
- Jedes Element hat ein **Start-Tag** `<p>` und ein **End-Tag** `</p>`.
- Es gibt nur **eine** `<h1>` pro Seite.

## Bonus
- [ ] Füge mit `<hr>` eine Trennlinie zwischen den Abschnitten ein.
- [ ] Mache mit `<br>` einen Zeilenumbruch in einem Absatz.
